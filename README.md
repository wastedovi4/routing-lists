# routing-lists

Списки IP-сетей для policy-based routing: «всё, кроме России, — в туннель», с отдельными
зонами для Германии и ОАЭ.

Снимок снят **11 октября 2026** с боевого шлюза и выложен как есть. Это рабочие списки,
по которым годами ходил живой трафик, а не теоретическая выборка.

## Состав

| Файл | Сетей | Адресов | Что это |
|---|---:|---:|---|
| `lists/other_ips.txt` | 315 669 | 4 107 103 488 | Весь IPv4 **минус Россия** — основной список, по нему уходит в туннель всё зарубежное |
| `lists/germany_ips.txt` | 17 466 | 136 938 240 | Германия |
| `lists/uae_ips.txt` | 903 | 5 601 024 | ОАЭ |
| `lists/russia_ips.txt` | 10 965 | 45 324 544 | Россия — для обратной схемы («в туннель только РФ») либо для исключений |

Проверено при публикации: пересечение `other_ips` с `russia_ips` — **ноль сетей**, то есть
российские диапазоны в основной список действительно не попали. Столько же (ноль) у
`germany_ips` с `russia_ips`.

Формат — по одной CIDR-сети в строке, пустые строки и `#`-комментарии допустимы:

```
0.0.0.0/8
1.0.0.0/24
1.0.1.0/23
```

## Происхождение

Российская часть собрана из [antifilter.download](https://antifilter.download/list/allyouneed.lst)
(`allyouneed.lst`), страновые зоны — из распределений RIR. Файлы статические: с момента
снимка диапазоны у провайдеров успели поменяться, и чем дальше, тем сильнее. Для задач,
где нужна свежесть, берите данные из источника; этот репозиторий — зафиксированный,
проверенный срез, удобный тем, что его можно применить одной командой и получить ровно то
поведение, которое было на шлюзе.

## Применение

```bash
sudo ./scripts/apply-routes.sh wg10 11
```

Первый аргумент — интерфейс туннеля, второй — номер таблицы маршрутизации. Скрипт
складывает все три зарубежные зоны в одну таблицу через `ip -batch` (одной транзакцией:
поштучное добавление 300+ тысяч маршрутов занимает минуты, пакетное — секунды), после чего
направляет в неё трафик из указанных подсетей-источников.

Подсети-источники задаются переменной окружения `SRC_NETS`, через пробел:

```bash
SRC_NETS="10.250.0.0/16 10.254.0.0/16" sudo ./scripts/apply-routes.sh wg10 11
```

Снять всё, что скрипт создал:

```bash
sudo ./scripts/apply-routes.sh --flush wg10 11
```

### Грабля, на которую стоит не наступать

Правила `ip rule` без явного `pref` получают приоритет «минимальный из существующих минус
один». Если такие правила расставляет ещё и другая система (панель, демон, второй скрипт),
то порядок между ними определяется тем, кто стартовал последним, — и однажды трафик пойдёт
не в тот туннель без единой ошибки в логах. Поэтому в скрипте приоритеты заданы явно
(`SRC_PREF`, по умолчанию 100), и менять их стоит осознанно.

## Лицензия

Списки получены из открытых источников и публикуются как есть, без гарантий.
